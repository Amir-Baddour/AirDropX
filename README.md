# AirDropX
Multi-tenant airdrop campaign platform (Web2, mocked payouts). Companies register, build an airdrop, and publish it as a public campaign page on DigitalOcean Spaces. Java 17 + Spark + PostgreSQL, with a full CI/CD pipeline: GitHub Actions → GHCR → Docker on DigitalOcean, with staging, approval-gated production and auto-rollback.
